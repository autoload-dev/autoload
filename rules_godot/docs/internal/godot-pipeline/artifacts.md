# Artifact Catalogue

See [scope and notation](README.md). Path examples are conventional for the pinned version;
project data directories, feature tag variants and plugins can change them. Producer/consumer
IDs resolve in [operations](operations.md). Rows describe classes, including non-file inputs.
All code that runs may additionally read ART-EXTERNAL; unproved reads are not assumed absent.

## Sources, identity and configuration

| ID | Artifact / identity | Producer → consumers; role and conditions | Evidence |
|---|---|---|---|
| ART-DECL | BUILD/Starlark/MODULE, pins, configurable attributes, toolchain registration, ordered patch/module declarations | Authored build input → analysis and all affected operations. Labels/configurations influence output/action ownership independently of source bytes. | R [R01](evidence.md#r01), [R07](evidence.md#r07) |
| ART-SOURCE | Authored or generated scenes/resources/scripts/shaders/images/audio/fonts/translations/data and their declared reference closure | Checkout/generator → scan/import/init/check/test/run/export. Generated resources are ordinary inputs once produced. Text/binary/custom format determines discoverability and conversion. | F/R [S04](evidence.md#s04), [R01](evidence.md#r01) |
| ART-NAMESPACE | Logical res:// paths, root/directory membership/case, .gdignore, nested project.godot, project-data path, declared resource paths/owners | Filesystem/declarations → discovery, imports, metadata, graph, loading. Same bytes at another logical path need not have the same cache identity/UID. Extension library autodetection may also read directory listings. | F/R [S04](evidence.md#s04), [S05](evidence.md#s05), [S09](evidence.md#s09), [R01](evidence.md#r01) |
| ART-UID-SIDECAR | Authored or generated <resource>.uid where its loader supports sidecars | Scan/editor output → later scan/load/export and checkout input after writeback. Not every resource format has a .uid sidecar. Authored identities and registry collision state affect generation. | F/E [S04](evidence.md#s04), [S05](evidence.md#s05), [E01](evidence.md#e01) |
| ART-IMPORT-SIDECAR | <source>.import: importer/version/type/UID, remap paths/feature variants, group/generator parameters, params and generated/dependency paths | Authored input or OP-IMPORT output → subsequent import validation, runtime remapping and export. Includes options read from referenced group members. | F/E [S04](evidence.md#s04), [S06](evidence.md#s06), [E01](evidence.md#e01) |
| ART-PROJECT | Authored project.godot, generated/project.binary configuration, contributions and explicit overrides | Authored or OP-CONFIG/OP-PCK output → relevant engine startup. Includes resource-valued settings, autoload name/path/singleton policy, main scene and feature overrides. Files named by a setting still need declared dependencies. | F/R [S02](evidence.md#s02), [R02](evidence.md#r02) |
| ART-OVERRIDE | override.cfg, custom project_settings_override path/disable policy/build capability, applicable source/main-pack/executable-adjacent locations | Conditional startup input; editor setup ignores this override path. Distinguish from explicit ruleset literal setting_overrides and pack-only settings. | F [S02](evidence.md#s02), [S03](evidence.md#s03) |
| ART-PURPOSE-CONFIG | Resolved per-purpose (runtime, import, editor, export) project.godot Files, pack-only settings and config manifests | OP-CONFIG → selected purpose. The baseline wrapper rebuilds plugin enabled lists, removes autoload/main-scene/resource-valued settings and inactive overrides from the import purpose's configuration. Equal configuration for one purpose is not whole-project equality. | R [R02](evidence.md#r02) |
| ART-FEATURES | Editor feature tag query results; operating-system/CPU/variant/export/custom/server feature tags and overrides | Toolchain/config/preset/plugins or OP-FEATURES → per-purpose configuration, importer/library/remap/export choice. The editor's own feature tags and those of the export differ. | F/R [S02](evidence.md#s02), [S08](evidence.md#s08), [R02](evidence.md#r02) |

## Engine, tools, plugins and extensions

| ID | Artifact / identity | Producer → consumers; role and conditions | Evidence |
|---|---|---|---|
| ART-ENGINE | Actual editor executable/data, compiled modules/build options/patches, version/capabilities and built-in importers/exporters | Acquisition/source build → every engine invocation. The runtime an application ships is ART-RUNTIME, not an automatic PCK-export input. | F/R [S01](evidence.md#s01), [S03](evidence.md#s03), [R07](evidence.md#r07) |
| ART-TOOLS | Action helper code/templates/runfiles, external importer executables (e.g. Blender), versions/arguments; compiler/linker/SDK/JDK/SCons/Python tools as applicable | Tool repositories/toolchains → respective operations only. Importer external tools and their auxiliary inputs are conditional; not every import requires an Android/iOS SDK. | F/R [S06](evidence.md#s06), [R02](evidence.md#r02), [R05](evidence.md#r05), [R07](evidence.md#r07) |
| ART-EDITOR-SETTINGS | Global/versioned editor settings, data/config/cache roots, executable-side self-contained marker and editor theme/scale | User/environment/tool install → conditional editor/import behavior; editor may update them. Isolation of ordinary HOME/XDG roots does not prove self-contained or arbitrary plugin IO absent. | F/R [S06](evidence.md#s06), [R02](evidence.md#r02) |
| ART-PLUGIN | plugin.cfg, enabled-purpose list, scripts/resources, registration code and declared closures | Engine/project activation → importer/exporter/editor behavior. Same plugin can participate in multiple phases and register additional facilities. | F/R [S03](evidence.md#s03), [S06](evidence.md#s06), [S08](evidence.md#s08), [R02](evidence.md#r02) |
| ART-IMPORTER | Built-in/custom importer implementation/options/defaults/version, group membership, post-import scripts (including path resolution), generated-file contract | Engine/plugin/resource config → OP-IMPORTERS/OP-IMPORT. Grouped import is a multi-member conversion; a file-per-action split is not universally correct. | F [S04](evidence.md#s04), [S06](evidence.md#s06) |
| ART-EXT-DESC | .gdextension entry symbol, version/reload policy, feature-tagged libraries/dependencies, AAR marker/autodetection policy | Authored/template → enabled import/init/editor/check/export/run phases. Paths, features and initialization order matter alongside bytes. | F/R [S09](evidence.md#s09), [R05](evidence.md#r05) |
| ART-EXT-LIBS | Extension editor/runtime libraries (.so/.dylib/static archives/frameworks/XCFrameworks) plus library dependencies, CcInfo/link/registration/symbol inputs | C++ build/prebuilt → editor loading or runtime linkage/delivery. The extension editor library and the mobile extension runtime library can differ under one extension. | F/R [S09](evidence.md#s09), [R05](evidence.md#r05), [R07](evidence.md#r07) |
| ART-PLATFORM-LIBS | Platform libraries: Java/AAR/Maven/Android resources/manifests, Objective-C/Swift/framework resources/plists, native link options | Extension/library providers → application merge/link/package beside ART-EXT-LIBS. They are dependencies even when absent from PCK bytes. | R [R05](evidence.md#r05) |
| ART-RUNTIME | Desktop runtime executable, engine AAR/classes/engine library, static engine library/XCFramework and variant/provider metadata | Prebuilt/source build → packaged execution. The runner uses the ART-ENGINE editor for packs; an application uses its selected runtime. | F/R [S08](evidence.md#s08), [R04](evidence.md#r04), [R05](evidence.md#r05) |

## Import and initialization products

| ID | Artifact / identity | Producer → consumers; role and conditions | Evidence |
|---|---|---|---|
| ART-IMPORTABLE | The baseline wrapper's suffix-marker tree from editor-recognized minus runtime-recognized loaders | OP-IMPORTERS → lazy import unit expansion. Marker files are probe data, not converted resources. | R [R02](evidence.md#r02) |
| ART-IMPORTED | .godot/imported converted files, variants, .md5 and importer auxiliary outputs; some formats have editor-only variants/metadata | OP-IMPORT → init/editor/run/export through sidecar remaps. Paths and cache roots are not universal constants. | F/E [S04](evidence.md#s04), [S06](evidence.md#s06), [E01](evidence.md#e01) |
| ART-IMPORT-RESULT | Import result: per-import-unit Bazel tree containing import.tar or nothing | OP-IMPORT → downstream import/init/editor/export. Wrapper retains changed converted files and own sidecars, not arbitrary importer output everywhere. | R [R02](evidence.md#r02) |
| ART-FS-CACHE | .godot/editor/filesystem_cache10 and scan/reimport state | Editor scan/import reads/writes → later scans. Membership, mtimes, MD5s, destination presence and importer version/settings participate; this is not Bazel's action cache. | F/E [S04](evidence.md#s04), [E01](evidence.md#e01) |
| ART-CLASS-CACHE | .godot/global_script_class_cache.cfg: language/name/base/path/icon/tool/abstract metadata | OP-INIT/editor/export filtering → source startup, GdUnit recognition, runtime class registration. Selection-dependent. | F/E [S02](evidence.md#s02), [S04](evidence.md#s04), [S13](evidence.md#s13), [E01](evidence.md#e01) |
| ART-UID-CACHE | .godot/uid_cache.bin UID-to-path registry | Scan/init/export → UID lookup and collision state; additional pack loading can merge entries. Authored UID sidecars and warm registry are different inputs. | F/E [S05](evidence.md#s05), [E01](evidence.md#e01) |
| ART-GROUP-CACHE | .godot/scene_groups_cache.cfg and project/global scene-group metadata | Editor filesystem/group discovery → later editor group inspection and tooling. Conditional; distinct from class/UID caches, not observed in the tiny probe. | F [S04](evidence.md#s04) |
| ART-EXT-LIST | .godot/extension_list.cfg naming descriptors | Wrapper staging/editor discovery → startup extension manager. List availability, physical library presence and actual registration are three separate conditions. | F/R [S09](evidence.md#s09), [R02](evidence.md#r02) |
| ART-INITIALIZED | Whole-project initialization: changed staged project/editor/global state | OP-INIT → source run/editor/sidecar extraction. Unlike per-import-unit capture, initializer retains changed files across staged project; no promise of operation-subset precision today. | R [R01](evidence.md#r01), [R02](evidence.md#r02) |
| ART-RENDER-CACHE | Renderer shader caches, driver/compiler cache state and optional baked shader containers | Conditional renderer/export execution ↔ rendering. Engine/source/defines/API/settings/compiler can matter; not every headless import uses a GPU or emits these. | F [S07](evidence.md#s07), [S12](evidence.md#s12) |

## Export selection, conversion and packs

| ID | Artifact / identity | Producer → consumers; role and conditions | Evidence |
|---|---|---|---|
| ART-GRAPH | Resource path/relationship/config manifests and bounded static resource graph JSON | Analysis/OP-GRAPH → queries/OP-SELECT. Opaque/dynamic references remain explicit or conservative; this output cannot discover undeclared Bazel inputs. | R [R01](evidence.md#r01), [R06](evidence.md#r06) |
| ART-SELECTION | .selection.json explanation, .content.json path-to-source identity and required-pack availability descriptors | OP-SELECT → export validation/exclusion and downstream pack selection. Selected output content does not shrink current declared export inputs. | R [R01](evidence.md#r01), [R06](evidence.md#r06) |
| ART-PRESET | export_presets.cfg preset platform/mode/CPU (`binary_format/architecture`)/features/filters/selection/script conversion/options | Authored upstream or generated wrapper → OP-PCK/OP-SHELL. The baseline ruleset generates a preset; it does not consume arbitrary authored presets as such. | F/R [S08](evidence.md#s08), [R02](evidence.md#r02) |
| ART-CREDENTIALS | Export credentials file/secret references, encryption key/seed/filter policy and applicable environment overrides | Conditional encrypted upstream export/signing input. Catalogue records dependency kinds, never values. Current isolated PCK wrapper does not stage arbitrary credentials and scrubs encryption env. | F/R [S08](evidence.md#s08), [S12](evidence.md#s12), [R02](evidence.md#r02) |
| ART-EXPORT-CACHE | .godot/exported/<customization-hash>/file_cache, converted/customized resources and shader_baker cache | Export callbacks → later customization/export reuse. Separate from resource imports; isolated baseline wrapper does not publish it as persistent public output. | F [S08](evidence.md#s08), [S12](evidence.md#s12) |
| ART-EXPORTED | Converted/remapped runtime resources, filtered .import, .remap, .gdc token buffers, project.binary and filtered class/UID/extension metadata | OP-PCK → PCK members. .gdc is a tokenizer buffer, optionally compressed, not VM/native bytecode. | F [S08](evidence.md#s08), [S10](evidence.md#s10) |
| ART-PRIOR-PCK | Prior/base pack bytes or pack identity/availability metadata | Conditional upstream patch export reads prior bytes; required_packs selection reads ART-SELECTION identity metadata. These are different edges, neither implies physical delivery/loading. | F/R [S08](evidence.md#s08), [R01](evidence.md#r01) |
| ART-PCK | Standalone .pck (or upstream embedded/zipped content form), format/version and feature-selected content | OP-PCK → pack run/mount/application packaging. The baseline wrapper emits a standalone .pck and export report; delivery of extension libraries requires separate physical/link inputs. Current wildcard policy may also archive raw library bytes. | F/R [S08](evidence.md#s08), [S09](evidence.md#s09), [R02](evidence.md#r02) |
| ART-EXPORT-FACTS | Export facts: ruleset .facts.json feature tags/options/defaults/effective settings/versions/name translations | OP-SHELL second throwaway export → shell file/asset generation. This is wrapper probe data, not a standard Godot cache. | R [R08](evidence.md#r08) |
| ART-SHELL-ASSETS | Rendered/copied application icons, splash, Apple catalogs/icns, default engine images | Probe/image tools → application resources. Depends conditionally on source/imported images, engine profile constants and Android/Apple tools. | R [R08](evidence.md#r08), [R05](evidence.md#r05) |

## Applications, execution and side effects

| ID | Artifact / identity | Producer → consumers; role and conditions | Evidence |
|---|---|---|---|
| ART-SHELL-FILES | Generated activity/native startup/plugin hooks, manifest/plist/privacy/localizations/themes/launch data/command line | Export facts/engine profiles/templates/application attrs/library metadata → compile/merge/link/package. Keep transitive platform library contributions. | R [R05](evidence.md#r05), [R08](evidence.md#r08) |
| ART-APPLICATION | Runnable desktop tree/archive, macOS .app, Android APK/AAB, iOS app/IPA | OP-APPLICATION → run/install/sign. Linkage/resource packaging can change while PCK bytes remain equal. Mobile packaging can include signing. | R [R05](evidence.md#r05) |
| ART-SYMBOLS | Unstripped objects/binaries, dSYM, symbol ZIP and build-ID/UUID association | Native compile/link/OP-SYMBOLS → crash tooling; stripped copies enter app. Post-hoc dSYM generation cannot recover missing object DWARF. | R [R05](evidence.md#r05) |
| ART-SIGNING | Identity/entitlements/provisioning/keystore refs, signing executable and conditional keychain/service state | Declared/local signing setup → OP-SIGN; values are not research output. Mode determines reproducibility/locality. | R/F [R05](evidence.md#r05), [S08](evidence.md#s08) |
| ART-SIGNED | Signed copy/archive/signature metadata or signed application package | OP-SIGN → installation/distribution/run; macOS operation preserves unsigned original and performs verification, not notarization. | R [R05](evidence.md#r05) |
| ART-LAUNCH | Generated launcher/run manifest/import list/case list, test adapter/framework code, main/args/env/filter/shard/timeout/report policy | Analysis/test adapters → editor/check/test/run. Case candidates and dependency availability differ; in-memory script compilation/static state is not necessarily a persistent artifact. | F/R [S03](evidence.md#s03), [S13](evidence.md#s13), [R04](evidence.md#r04) |
| ART-PACK-STATE | Delivered pack set/load order/replace_files/offset, virtual paths, already-loaded resources, class registry and UID state | Startup/OP-MOUNT → subsequent loads/runtime. Mounting does not reload project settings/autoloads/extensions. | F/R [S02](evidence.md#s02), [S05](evidence.md#s05), [S09](evidence.md#s09), [R04](evidence.md#r04) |
| ART-EXTERNAL | Actual filesystem/permissions/user:// saves, operating-system APIs/devices/services/network, clocks/RNG, locale/environment, renderer/driver/display and untracked plugin reads | Conditional input and output of executed app/plugin/tool code. Isolation/tagging/declared inputs are policies, not proof every external influence is captured. | F/R/U [S03](evidence.md#s03), [S06](evidence.md#s06), [R04](evidence.md#r04), [B03](evidence.md#b03) |
| ART-REPORT | Exit status, logs/engine diagnostics, checker/GdUnit JUnit/results, runner timing/failure JSON, export report and Bazel undeclared outputs | Engine/wrapper/test execution → user/test cache/diagnostics. Diagnostics policy itself affects success. Not all reports are deterministic artifact content. | R [R02](evidence.md#r02), [R04](evidence.md#r04) |
| ART-SIDECAR-LIST | JSON of generated missing sidecars, checkout paths/owner/content | OP-SIDECARS extraction → writer/check/editor; writeback creates later authored ART-UID-SIDECAR/ART-IMPORT-SIDECAR. Existing files are not overwritten. | R [R03](evidence.md#r03) |
| ART-EDITOR-VIEW | .godot-editor editor view symlinks/copies/bookkeeping/project metadata, checkout/config edits | Editor tool + actual checkout + user action ↔ OP-EDITOR. Interactive writes are side effects, not cacheable build outputs. | R [R03](evidence.md#r03) |
| ART-SCRATCH | Temporary project roots, tmpproject.binary/export locks/logs, normalized HOME/XDG/TMPDIR trees | Wrapper/engine execution → scratch staging/state; may mediate concurrency. Separate from retained output artifacts and persistent user state. | F/R [S08](evidence.md#s08), [R02](evidence.md#r02), [R04](evidence.md#r04) |
